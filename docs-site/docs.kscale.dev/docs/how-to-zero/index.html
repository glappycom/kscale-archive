How To Zero

unplug servos to make them floppy, then you can set zeros using https://github.com/kscalelabs/skillet/blob/master/skillet/setup/setup_zeroing.py

ideally you do this with one of our custom 3d printed rigs

now at any point, if you want to return to the 0 you set, you can run python skillet/go_to_zero.py
