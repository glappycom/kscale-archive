# Humanoid Robot Grant

At K-Scale Labs, we are working towards a future where there are billions of useful humanoid robots. We think that this project should be the collective effort, rather than the work of a few companies.

Our grant program exists to support robotics enthusiasts around the world who want to help contribute to this goal. This person is someone who:

* Loves humanoid robots
* Has good ideas
* Believes in the open-source mission

The K-Scale Humanoid Robot Grant is an almost-no-strings-attached cash grant ranging from $10,000 to $25,000. The only requirement is that you make whatever you build open-source, so that the rest of the robotics community can benefit from it.

To apply, please fill out [this form](https://forms.gle/rBF7WsEvSFd6e5Zm8) with a video introducing yourself and your project. If you're looking for ideas on what to build, one good place to start is in [our Discord](https://discord.gg/rhCy6UdBRD).

Applications are evaluated on a rolling basis. Please be patient as we iron out the kinks 😊
