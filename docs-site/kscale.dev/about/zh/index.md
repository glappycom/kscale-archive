# 关于 | K-Scale Labs

K-Scale Labs 是一家充满创新精神的机器学习初创公司，专注于为未来的具身人工智能打造最前沿的软件。

我们位于硅谷核心地带，毗邻斯坦福大学。我们的团队由顶尖的工程师和研究人员组成，肩负着一个宏伟的使命——为数十亿台人形机器人铺就道路，让它们在家庭和工业劳动中成为人类的得力助手。

我们的首个革命性项目 Stompy 是一个开源的双足人形机器人，任何人都可以通过3D打印轻松制造。Stompy 作为一个低成本的机器人模板，既可定制，又可作为参考设计，开辟了无限可能。

如果您对构建或开发自己的机器人充满热情，请立即联系我们，一起开创未来的智能时代！
